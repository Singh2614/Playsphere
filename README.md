# PlaySphere

A React-powered gaming hub featuring Tic Tac Toe, Hangman, and Connect Four, with both single-player (AI) and two-player modes.

## Features

* **Three Classic Games**

  * **Tic Tac Toe**: Enjoy a quick match on a 3×3 grid.
  * **Hangman**: Guess the hidden word before hangman is drawn.
  * **Connect Four**: Strategically stack four tokens in a row.
* **Dual Modes**

  * **Single-Player**: Play against computer.
  * **Two-Player**: Play locally against a friend.
* **Responsive Design**
  Adapts seamlessly to desktop, tablet, and mobile screens.
* **Intuitive UI**
  Clean layout, clear game controls, and instant feedback.

## Installation

1. **Clone the repo**

   ```bash
   git clone https://github.com/Arunima2305/game-hub
   cd game-hub
   ```
2. **Install dependencies**

   ```bash
   npm install
   ```
3. **Start the development server**

   ```bash
   npm start
   ```
4. **Open**
   Navigate to `http://localhost:3000` in your browser.
